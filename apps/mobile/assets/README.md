# App assets

Drop these in when you run `npx @react-native-community/cli init` (they are not
generated by this repo):

## Launcher icon

- Source: a single 1024×1024 PNG, dark background, one calm mark (a thin circle
  or a single dot works with the app's tone — no bright colours, no "app store"
  gloss).
- Android: generate the `mipmap-*` densities + adaptive-icon foreground/background
  in Android Studio (Image Asset Studio) or with `@bam.tech/react-native-make`:
  ```bash
  npx react-native set-icon --path ./assets/icon-1024.png --background "#0d0d0d"
  ```
- Play Console listing icon: the same art at exactly **512×512**.

## Store graphics (Play Console)

- Feature graphic: **1024×500** PNG/JPG.
- Phone screenshots: at least **2**, 16:9 or 9:16, min 320px. Suggested shots:
  the Reflection Mirror, an Awareness Window, the Settings screen.

## Splash

- Optional. A plain `#0d0d0d` screen is fine — configure via
  `react-native-bootsplash` or the platform default.
